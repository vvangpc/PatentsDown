## 🆕 v3.2 — 下载修复 + 安装版 + 自动构建

### 修复

- 🐛 **直连模式 503 反爬** — 补全拟真浏览器请求头，并对 `503 / 429` 限流响应做指数退避重试，显著降低「直连失败」概率。
- 🐛 **浏览器兜底无法启动** — 弃用过旧的 `undetected-chromedriver`，改用标准 `Selenium`（内置 Selenium Manager 自动匹配驱动），可正常驱动 Chrome 148+。
- 🪟 **可见窗口 + 手动过验证** — 浏览器兜底不再后台静默运行，改为弹出真实窗口；遇到人机验证时可手动通过，程序自动继续（最长等待 180 秒）。

### 新特性

- 📦 **安装版（Setup）** — 新增 Inno Setup 安装包，采用目录(onedir)打包方式，**启动速度远快于单文件便携版**；安装到当前用户目录，无需管理员权限。
- 🤖 **GitHub Actions 自动构建** — 推送 `v*` 标签即自动构建便携版与安装版并发布到对应 Release。

### Release 资产说明

| 文件 | 说明 |
| --- | --- |

| `PatentsDown_v3.2_Portable.exe` | **便携版**（单文件免安装），首次启动需解压、略慢 |
