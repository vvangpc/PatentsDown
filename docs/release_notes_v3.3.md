## 🆕 v3.3 — UI 修复：长路径不再挤出按钮

### 修复

- 🐛 **「保存目录」长路径挤出按钮** — 当 PDF 所在目录或手选目录路径较长时，同一行右侧的「📂 选择目录」「🚀 开始下载」按钮会被路径标签的自然宽度推到可视区之外，缩小窗口后用户无法点击。本版本修复后，按钮在任何窗口宽度（含 minsize 700×580）下都保持完整可见、可点击。

### 改进

- ✂️ **路径中部省略显示** — 超长路径以 `C:\Users\Administrator\...\zip_2104` 形式紧凑显示，仅保留盘符头与末层目录名，按路径分隔符切分，不在文件夹名中间断字。
- 💡 **鼠标悬停看完整路径** — 在「保存目录:」路径文本上悬停约 0.4 秒，弹出浅黄色 tooltip 显示真实完整路径。
- 🔧 **加固 pack 顺序** — `dir_frame` 内先 pack 两个按钮（`side="right"`），再 pack 路径标签（`side="left", fill="x", expand=True`），按钮的 `reqwidth` 始终优先占位。与显示截断构成双保险。

> 内部实际使用的 `manual_save_dir` / `pdf_path` 仍是完整真实路径，下载流程不受截断影响。
